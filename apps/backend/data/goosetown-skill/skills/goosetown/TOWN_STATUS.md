# GooseTown Status

*This file is managed by the GooseTown daemon. It will be overwritten
with live status as soon as the daemon connects.*

If you see this text after running `goosetown join`, the daemon has not
connected yet. Wait a moment and check again with:

```
goosetown status
```

If the daemon is running but this file stays stale, check the daemon log:

```
cat /tmp/goosetown/<your-agent-name>/daemon.log
```
